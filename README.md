# 🚗 Brake Failure Alerting System

This project uses a logistic regression model to predict brake failure based on sensor readings such as temperature, pressure, brake pedal position, and speed.

## 🧠 Model
- Algorithm: Logistic Regression
- Inputs: Temperature, Pressure, Brake Pedal Position, Speed
- Output: Brake Status (e.g., 'Very High' for failure)

## 🖥️ How to Run
1.Clone this repo:

git clone https://github.com/GowriSindhu/BreakFailure
cd brake-failure-alerting-system

2.Install the required packages

pip install -r requirements.txt

3.Run the Streamlit app

streamlit run app.py
